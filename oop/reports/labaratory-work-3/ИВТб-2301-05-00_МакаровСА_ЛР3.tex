\section*{\hspace{12.5mm}Цель работы}
Цель работы: изучить и освоить принципы объектно-ориентированного программирования, включая инкапсуляцию, наследование и полиморфизм, путем создания иерархии классов в выбранной предметной области, взаимодействие с базой данных и графическим интерфейсом.

\section*{\hspace{12.5mm}Задание}
На основании согласованной в первой и второй лабораторной работе предметной области разработать приложение , используя классы и особенности java. Сведения об объектах предметной области необходимо хранить в БД.

\section*{\hspace{12.5mm}Решение}
Предметная область описывает управление ассортиментом блюд в заведении общественного питания. Система позволяет хранить информацию о различных блюдах, учитывать их специфические характеристики, рассчитывать итоговую цену для клиента в зависимости от этих характеристик и выводить информацию о блюде в удобном виде.

Программа содержит классы <<Dish>>, представлющий базовый класс блюда,  <<Pizza>>, наследованный от <<Dish>> и представлющий класс пиццы, <<Salad>> наследованный от <<Dish>> и представлющий класс салата. Также для создания заказов сущноствуют классы <<Order>> и <<OrderItem>>, представлющий блюдо в заказе.

Базовый класс <<Dish>> содержит:
\begin{itemize}
  \item[--] Поля:
    \begin{itemize}
      \item[--] private UUID id -- поле, означающее уникальный идентификатор;
      \item[--] private String name -- поле, означающее название блюда, строковый тип данных;
      \item[--] private int weight -- поле, означающее вес блюда, целочисленный тип данных;
      \item[--] private double price -- поле, цена блюда, формат с плавающей запятой;
    \end{itemize}
  \item[--] Конструкторы:
    \begin{itemize}
      \item[--] public Dish(String name, int weight, double price) - публичный конструктор, принимает  в качестве параметров название, вес и цену блюда;
      \item[--] public Dish(String name) - публичный конструктор, принимает название блюда в качестве параметра;
      \item[--] protected Dish() {} -- конструктор, необходимый для Hibernete;
    \end{itemize}
  \item[--] Абстрактные методы:
    \begin{itemize}
      \item[--] public abstract String displayInfo() -- публичный абстрактный метод, возвращающий информацию о блюде, не принимает параметров;
      \item[--] public abstract double calcFullPrice() -- публичный абстрактный метод, возвращающий полную цену блюда;
      \item[--] public abstract DishResponse getInfo() -- публичный абстрактный метод, возвращающий озвращающий информацию о блюде в необходимом формате для ответа на запрос к серверу.
    \end{itemize}
\end{itemize}

Для описания моделей Hibernete используются следущие нотации:
\begin{itemize}
  \item[--] @Entity -- используется для описания сущности:
  \begin{Verbatim}[tabsize=4]
  @Entity
  public abstract class Dish { ... }
  \end{Verbatim}
  \item[--] @Table(name = "dishes") -- используется для задания имени таблицы сущности в базе данных:
  \begin{Verbatim}[tabsize=4]
  @Table(name = "dishes")
  public abstract class Dish { ... }
  \end{Verbatim}
  \item[--] @Inheritance(strategy = InheritanceType.JOINED) -- задает стратегию наследования. Общие поля родительского класса в одной таблице, а специальные поля наследников в отдельных таблицах, связанных по идентификатору:
  \begin{Verbatim}[tabsize=4]
  @Inheritance(strategy = InheritanceType.JOINED)
  public abstract class Dish { ... }
  \end{Verbatim}
  \item[--] @PrimaryKeyJoinColumn(name = "dish\_id") -- используется в наследниках и показывает, что их первичный ключ одновременно является внешним ключом на запись в родительской таблице:
  \begin{Verbatim}[tabsize=4]
  @PrimaryKeyJoinColumn(name = "dish_id")
  public class Pizza extends Dish { ... }
  \end{Verbatim}
  \item[--] @OnDelete(action = OnDeleteAction.CASCADE) -- задает правила удаления записей в связанных таблицах:
  \begin{Verbatim}[tabsize=4]
  @OnDelete(action = OnDeleteAction.CASCADE)
  public class Pizza extends Dish { ... }
  \end{Verbatim}
  \item[--] @Id и @GeneratedValue -- используеются для создания уникального сгенерированного идентифифкатора:
  \begin{Verbatim}[tabsize=4]
  @Id
  @GeneratedValue
  private UUID id;
  \end{Verbatim}
  \item[--] @ManyToOne() и @OneToMany(mappedBy = "order", cascade = CascadeType.ALL, orphanRemoval = true) -- создают связь один ко многоим между сущностями:
  \begin{Verbatim}[tabsize=4]
  public class Order {
    @OneToMany(mappedBy = "order", cascade = CascadeType.ALL, orphanRemoval = true)
    private List<OrderItem> items = new ArrayList<>();
  }
  public class OrderItem {
    @ManyToOne()
    private Order order;
  }
  \end{Verbatim}
  \item[--] @JoinColumn(name = "order\_id") -- используется для указания по какому поля связывать сущности:
  \begin{Verbatim}[tabsize=4]
  public class OrderItem {
    @JoinColumn(name = "order_id")
    private Order order;
  }
  \end{Verbatim}
\end{itemize}

Разработаны серверные и клиентское приложение в виде веб-интерфейса. Серверное приложение содержит подключение к базе данных, конфигурацию моделей и контроллеры.

Подключение к базе даныых Postgres происходит с помощью следующих настроек подключения:

spring.datasource.username=root
spring.datasource.password=root
\end{Verbatim}

Для того, чтобы пользоватсья CRUD функциями у сущностей необходимо создать репозиторий. Например, для сущности <<Pizza>> репозиторий выглядит следующим образом:
\begin{Verbatim}[tabsize=4]
public interface PizzaRepository 
        extends JpaRepository<Pizza, UUID> {}
\end{Verbatim}

Репозитории для остальных сущностей выполняются аналогичным способом и содержат аналогичные методы.

Следующим шагом идет создание сервисов для управления данными, получаемых из репозитория. Например, <<PizzaService>> содержит следющие методы:
\begin{itemize}
  \item[--]public Pizza createPizza(Pizza pizza) -- метод, который создает новую запись о пицце:
  \begin{Verbatim}[tabsize=4]
    return pizzaRepository.save(pizza);
  \end{Verbatim}
  \item[--]public List<Pizza> getAllPizzas() -- метод, возвращающий весь список пицц, хранящаеся в базе данных:
  \begin{Verbatim}[tabsize=4]
    return pizzaRepository.findAll();
  \end{Verbatim}
  \item[--] public Pizza getPizzaById(UUID id) -- метод, возвращающий отдельную запись о пицце по уникальному идентификатору:
  \begin{Verbatim}[tabsize=4]
    return pizzaRepository.findById(id);
  \end{Verbatim}
  \item[--] public Pizza updatePizza(UUID id, Pizza pizzaDetails) -- метод, который обновляет записи о пицце по уникальному идентификатору:
  \begin{Verbatim}[tabsize=4]
    Pizza existingPizza = getPizzaById(id);
    existingPizza.setName(pizzaDetails.getName());
    existingPizza.setWeight(pizzaDetails.getWeight());
    existingPizza.setPrice(pizzaDetails.getPrice());
    existingPizza.setDough(pizzaDetails.getDough());
    return pizzaRepository.save(existingPizza);
  \end{Verbatim}
  \item[--] public void deletePizza(UUID id) -- метод, удаляющий запись о пицце по уникальному идентификатору:
  \begin{Verbatim}[tabsize=4]
    pizzaRepository.deleteById(id);
  \end{Verbatim}
  \item[--] public double calculatePizzaPrice(UUID id) -- метод, возвращающий полную стоимость пиццы по уникальному идентификатору;
  \item[--] public Pizza toggleDough(UUID id) -- метод, меняющий тип теста пиццы по уникальному идентификатору;
  \item[--] public String getPizzaDisplayInfo(UUID id) -- метод, возвращающий полное описание записи пиццы по уникальному идентификатору;
  \item[--] public String cutPizza(UUID id) -- метод, возвращающий сообщение о нарезании пиццы на кусочки по уникальному идентификатору.
\end{itemize}

Сервисы для остальных сущностей выполняются аналогичным способом и содержат аналогичные методы.
